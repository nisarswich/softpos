Swich — Collect & Pay Mockups

One app for merchants: collect payments, hold one balance, pay out and borrow. Each screen is a standalone, clickable HTML file — open one directly, or click through the flow. Every card below lists the internal states you can switch between using the control strip beneath the phone.

One app, one balance. Money you collect and money you pay out live in the same wallet and the same Activity list. Five tabs: Home · Activity · Collect · Pay · Credit. Activity has an All / Money in / Money out toggle. Cashiers see only Collect and their own sales.
1 · The five tabs
Start here. Every tab is a root screen with the same bottom bar.
Try this loop: Collect a payment (Collect → amount → Card → result), open Home and see it in Activity and in "pending settlement"; tap Simulate settlement on Home to move it into the balance; then Pay a vendor and watch the balance and Activity update. Use "Reset finance demo data" in any control strip to start over. Role switcher: Owner / Branch Manager / Solo see all five tabs; Cashier sees Collect + My Sales.
